# Feuille de route du projet étudiant

Ce document concerne l'organisation du travail du groupe, pas la trajectoire de déploiement chez Verdalia (voir `docs/08-trajectoire.md`). Les dates sont à fixer selon le calendrier du module : nous ne les connaissons pas.

| Étape | Objectif | Responsables | Sortie |
|---|---|---|---|
| 1. Appropriation | lire le premier jet et le cahier des charges officiel ; lister les écarts | tous | liste d'écarts dans une Issue |
| 2. Vérification des sources | confirmer RGPD, CNIL, code de commerce, AI Act | Personne 3 en lead | bibliographie à jour |
| 3. Amélioration par branche | enrichir chaque partie, Pull Requests | chacun | PR relues |
| 4. Intégration | fusion dans `main`, résolution des conflits | tous | `main` cohérent |
| 5. Livrables | régénérer le Word et le PowerPoint | Personne 2 en lead | fichiers contrôlés |
| 6. Soutenance | répétitions, questions | tous | script validé, 15 minutes tenues |
| 7. Rendu | checklist finale | tous | [CHECKLIST_RENDU](CHECKLIST_RENDU.md) cochée |
